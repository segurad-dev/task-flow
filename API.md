# API Reference — Task Flow

Базовый URL: `http://localhost:8000`

Интерактивная документация: **http://localhost:8000/docs** (Swagger UI)

---

## Аутентификация

Большинство эндпоинтов требуют JWT-токен в заголовке:

```
Authorization: Bearer <access_token>
```

---

## Auth

### POST /auth/register — Регистрация

Авторизация: **не требуется**

**Request body:**
```json
{
  "email": "user@example.com",
  "username": "user",
  "password": "secret123"
}
```

**Response 201:**
```json
{
  "id": 1,
  "email": "user@example.com",
  "username": "user"
}
```

**Ошибки:**

| Код | Описание |
|-----|----------|
| 400 | Email уже зарегистрирован |
| 422 | Невалидные данные (неверный формат email и т.д.) |

---

### POST /auth/login — Вход

Авторизация: **не требуется**

Формат запроса: `application/x-www-form-urlencoded` (OAuth2 стандарт)

**Request body:**
```
username=user@example.com&password=secret123
```

**Response 200:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

**Ошибки:**

| Код | Описание |
|-----|----------|
| 401 | Неверный email или пароль |

## Tasks

### GET /tasks/ — Список задач

Авторизация: **Bearer**

Возвращает задачи текущего пользователя. Результат кэшируется в Redis на 60 секунд.

**Query параметры:**

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `status` | string | — | Фильтр по статусу: `todo`, `in_progress`, `done`, `cancelled` |
| `skip` | int | 0 | Смещение для пагинации |
| `limit` | int | 20 | Максимум задач в ответе |

**Response 200:**
```json
[
  {
    "id": 1,
    "title": "Написать тесты",
    "description": null,
    "status": "todo",
    "project_id": 1,
    "assignee_id": 1,
    "created_at": "2025-01-01T10:00:00",
    "updated_at": "2025-01-01T10:00:00"
  }
]
```

**Ошибки:**

| Код | Описание |
|-----|----------|
| 401 | Токен отсутствует или невалиден |

---

### POST /tasks/ — Создать задачу

Авторизация: **Bearer**

**Request body:**
```json
{
  "title": "Написать тесты",
  "description": "Покрыть все эндпоинты",
  "project_id": 1,
  "assignee_id": 1
}
```

Поля `description` и `assignee_id` необязательны.

**Response 201:**
```json
{
  "id": 2,
  "title": "Написать тесты",
  "description": "Покрыть все эндпоинты",
  "status": "todo",
  "project_id": 1,
  "assignee_id": 1,
  "created_at": "2025-01-01T11:00:00",
  "updated_at": "2025-01-01T11:00:00"
}
```

**Ошибки:**

| Код | Описание |
|-----|----------|
| 401 | Токен отсутствует или невалиден |
| 422 | Невалидные данные (например, отсутствует `project_id`) |

### PATCH /tasks/{task_id} — Обновить задачу

Авторизация: **Bearer**

Все поля необязательны — обновляются только переданные.
При смене статуса на `done` автоматически проставляется `completed_at`.
При смене статуса отправляется уведомление через Celery (асинхронно).

**Request body:**
```json
{
  "title": "Новый заголовок",
  "description": "Новое описание",
  "status": "in_progress",
  "assignee_id": 2
}
```

Допустимые значения `status`: `todo`, `in_progress`, `done`, `cancelled`

**Response 200:**
```json
{
  "id": 1,
  "title": "Новый заголовок",
  "description": "Новое описание",
  "status": "in_progress",
  "project_id": 1,
  "assignee_id": 2,
  "created_at": "2025-01-01T10:00:00",
  "updated_at": "2025-01-01T13:00:00"
}
```

**Ошибки:**

| Код | Описание |
|-----|----------|
| 401 | Токен отсутствует или невалиден |
| 404 | Задача не найдена |
| 422 | Невалидный статус |

---

## Analytics

### GET /analytics/project/{project_id} — Статистика проекта

Авторизация: **Bearer**

**Response 200:**
```json
{
  "project_id": 1,
  "total": 10,
  "done": 7,
  "in_progress": 2,
  "todo": 1,
  "completion_rate": 70.0,
  "avg_completion_hours": 4.5
}
```

| Поле | Описание |
|------|----------|
| `total` | Общее количество задач в проекте |
| `done` | Количество завершённых задач |
| `in_progress` | Количество задач в работе |
| `todo` | Количество задач в очереди |
| `completion_rate` | Процент выполнения (done / total × 100) |
| `avg_completion_hours` | Среднее время выполнения в часах (от created_at до completed_at) |

**Ошибки:**

| Код | Описание |
|-----|----------|
| 401 | Токен отсутствует или невалиден |

---
